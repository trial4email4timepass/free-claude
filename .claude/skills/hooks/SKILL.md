# Hooks

## Goal
Write a set of strong, varied opening lines (hooks) for the user's content — the line that earns the next three seconds of attention.

## Inputs to gather (ask only if truly missing)
- What the content is about (topic/product/story)
- Platform (video, post, email subject, ad) — hook style differs by platform
- Target audience and tone (bold, curious, controversial, relatable)

## Workflow
1. Identify the single sharpest claim, tension, or curiosity gap in the content.
2. Write hooks across multiple proven patterns: bold claim, surprising stat, direct question, "I used to think X", contrarian take, relatable pain point, open loop.
3. Keep each hook short — one or two sentences max, platform-appropriate length.
4. Mark which hook types tend to perform best for the stated platform.

## Output template
```markdown
# Hooks: <topic>

1. **[Bold claim]** <hook text>
2. **[Curiosity gap]** <hook text>
3. **[Contrarian]** <hook text>
4. **[Relatable pain]** <hook text>
5. **[Question]** <hook text>
6. **[Stat/surprise]** <hook text>

**Strongest pick for <platform>:** #<n> — why
```

## Avoid
- Generic openers ("In today's video, we'll talk about...")
- Clickbait that the content can't actually deliver on
- One hook style repeated six times with minor wording changes
