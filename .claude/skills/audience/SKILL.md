# Audience

## Goal
Define a specific, usable target audience — narrow enough to make marketing/content decisions easier, not a vague "everyone who might like this."

## Inputs to gather (ask only if truly missing)
- Product/service/content topic
- Any existing customer/audience data (even anecdotal)
- Whether this is B2C or B2B (changes the framing entirely)

## Workflow
1. Identify who has the problem this product/content solves most acutely — start from the pain, not demographics.
2. Narrow to a primary audience segment (it's fine, even good, to exclude people) and note 1-2 secondary segments if relevant.
3. Describe the audience across: demographics/firmographics (brief), psychographics (values, fears, aspirations), current behavior (where they are, what they already do about this problem).
4. State why this audience specifically, and what would disqualify someone from being a good fit.

## Output template
```markdown
# Target Audience: <product/topic>

## Primary audience
- Who: <description>
- Core pain/need: <what draws them>
- Where they are: <channels/communities>
- Current behavior: <what they do today about this problem>

## Secondary audience (if any)
<brief>

## Who this is NOT for
<disqualifiers — keeps the definition sharp>
```

## Avoid
- An audience so broad it doesn't inform any decision ("anyone interested in fitness")
- Demographics with no psychographic or behavioral grounding
