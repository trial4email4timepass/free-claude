# Repurpose

## Goal
Take one existing piece of content and extract multiple distinct, native-feeling pieces for other formats/platforms — not just the same text pasted in shorter form.

## Inputs to gather (ask only if truly missing)
- The source content (paste it, or a clear summary if it's long)
- Target formats/platforms wanted (e.g. carousel, thread, Reel script, newsletter blurb, LinkedIn post)

## Workflow
1. Extract the source's core ideas: the main claim, 2-4 supporting points, and any standout quote/stat/story.
2. For each target format, adapt — don't just truncate. Match the format's native conventions (thread = numbered hook + payoff tweets; carousel = one idea per slide; Reel = script with hook/body/CTA).
3. Make sure each output could stand alone without the reader having seen the source.
4. Note which extracted idea each output is built around, so the user can trace it back.

## Output template
```markdown
# Repurposed: <source title>

## <Format 1, e.g. Twitter/X thread>
<full output, ready to post>
*(Built around: <core idea used>)*

## <Format 2, e.g. LinkedIn post>
...
```

## Avoid
- Copy-pasting the same paragraph into every format
- Losing the source's core insight in translation
- Producing outputs that only make sense if you've already read the source
