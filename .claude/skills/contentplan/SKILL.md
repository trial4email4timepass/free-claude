# Content Plan

## Goal
Produce a structured plan that connects a specific goal (growth, leads, launch, authority) to concrete content pieces — not a generic list of post ideas.

## Inputs to gather (ask only if truly missing)
- The goal (what does success look like, and by when)
- Platform(s) and current audience size/stage
- Content pillars or topics already in play, if any
- Resources/constraints (solo creator? team? budget?)

## Workflow
1. State the goal as a measurable outcome.
2. Define 3-5 content pillars that ladder up to the goal — each pillar should have a clear "why this helps the goal."
3. Under each pillar, propose specific content pieces (not just themes) with format and intended action from the viewer.
4. Sequence the plan (what comes first and why) rather than presenting an unordered bucket.
5. Note how you'll know it's working (the metric each pillar should move).

## Output template
```markdown
# Content Plan: <goal>

**Goal:** <measurable outcome, timeframe>

## Pillar 1 — <name>
Why it serves the goal: <one line>
- <content piece> (<format>) → <viewer action>
- <content piece> (<format>) → <viewer action>

## Pillar 2 — <name>
...

## Sequence
1. <what ships first, why>
2. <what ships next>

## Success metric
<what to track per pillar>
```

## Avoid
- Pillars with no stated link to the goal
- A content list that's really just a brainstorm with no sequencing
