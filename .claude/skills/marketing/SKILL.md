# Marketing Strategy

## Goal
Produce a coherent marketing strategy that connects the target audience, positioning, and channels into a plan — not a grab-bag of tactics.

## Inputs to gather (ask only if truly missing)
- Product/service/brand and what it does
- Target audience (or note that `audience`/`persona` skills should run first)
- Budget/resource level (bootstrapped vs. funded — changes viable channels)
- Primary goal (awareness, leads, sales, retention)

## Workflow
1. State the goal in measurable terms.
2. Confirm/derive the target audience and core positioning (one sentence: for [who], [product] is the [category] that [benefit], unlike [alternative]).
3. Choose channels based on where the audience actually is and the budget level — justify each channel choice, don't list every channel that exists.
4. For each channel, give the specific play (not just "post on Instagram" but what kind of content/cadence/offer).
5. Define how success will be measured per channel.

## Output template
```markdown
# Marketing Strategy: <brand/product>

**Goal:** <measurable outcome>
**Positioning:** <one-sentence positioning statement>

## Channel 1 — <name>
Why this channel: <one line>
Play: <specific tactic>
Success metric: <metric>

## Channel 2 — <name>
...

## Budget/resource note
<what this assumes>
```

## Avoid
- Listing every possible channel instead of the ones that fit the audience/budget
- Tactics with no stated success metric
- Skipping positioning and jumping straight to channels
