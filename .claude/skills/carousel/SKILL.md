# Carousel

## Goal
Structure information into a slide-by-slide carousel that hooks on slide 1 and delivers one clear idea per slide.

## Inputs to gather (ask only if truly missing)
- Topic/source material
- Platform (Instagram, LinkedIn — slide count and tone conventions differ)
- Number of slides desired (default 6-10)

## Workflow
1. Write a strong slide 1 hook — it must work as a standalone stopper, since it's what shows in-feed.
2. Break the content into one idea per slide — each slide should be readable in 2-3 seconds, not a paragraph.
3. Build a clear progression: hook → problem/context → points → summary/payoff → CTA slide.
4. Note any visual cue per slide (icon, image idea, emphasis) to guide design, without designing the actual graphic.

## Output template
```markdown
# Carousel: <topic>

## Slide 1 (Hook)
<text> — *visual: <cue>*

## Slide 2
<text> — *visual: <cue>*

...

## Slide N (CTA)
<text>
```

## Avoid
- Cramming multiple ideas onto one slide
- A weak hook slide that doesn't work outside the swipe
- Skipping the closing CTA slide
