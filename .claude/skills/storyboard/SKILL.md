# Storyboard

## Goal
Break an idea or script into a sequence of concrete, shootable/visual scenes — not just a text outline.

## Inputs to gather (ask only if truly missing)
- The idea or script to storyboard
- Format (short-form video, ad, explainer, presentation)
- Approximate length / number of scenes desired

## Workflow
1. If given a script, split it into natural beats (hook, setup, payoff, CTA). If given only an idea, first sketch the narrative beats, then storyboard them.
2. For each scene, describe: what's on screen, camera/framing note, on-screen text (if any), and the audio/voiceover line for that beat.
3. Keep scenes short — each should cover one beat, not a whole segment.
4. Note pacing: which scenes should be fast cuts vs. held longer.

## Output template
```markdown
# Storyboard: <title>

## Scene 1 — <beat name, e.g. Hook>
- **Visual:** <what's on screen / framing>
- **On-screen text:** <if any>
- **VO / dialogue:** <line>
- **Pacing:** <fast cut / held>

## Scene 2 — <beat name>
...
```

## Avoid
- Vague visual descriptions ("show something engaging")
- Skipping the audio/VO line — visuals and audio must be storyboarded together
- Too many scenes for a short-form format (keep it tight)
