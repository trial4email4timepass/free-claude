# Ideate

## Goal
Take a single seed idea and branch it into several genuinely distinct concepts — not restatements of the same thing.

## Inputs to gather (ask only if truly missing)
- The seed idea
- What "distinct" should mean here (different audience? different format? different mechanism?)
- Number of concepts wanted (default 4-6)

## Workflow
1. Identify the core mechanism or value of the seed idea — what makes it work.
2. Branch along multiple axes: change the audience, the format, the price/effort level, the emotional angle, or the constraint being relaxed.
3. For each concept, state what's kept from the seed and what's changed.
4. Rate each concept on effort vs. potential impact so the user can prioritize.

## Output template
```markdown
# Ideation: <seed idea>

**Core mechanism kept across all concepts:** <one line>

## Concept 1 — <name>
- What changed: <axis>
- Description: <2-3 lines>
- Effort: Low/Med/High · Potential: Low/Med/High

## Concept 2 — <name>
...

## Recommendation
<Which concept to prototype first, and why.>
```

## Avoid
- Concepts that are just reworded versions of the seed
- Skipping the "what changed" line — that's the whole point of ideation
