# Reel

## Goal
Produce a tight short-form video concept (under ~60 seconds) with a clear hook, body, and CTA — built for retention, not just information dump.

## Inputs to gather (ask only if truly missing)
- Topic/message
- Platform nuance (TikTok, Reels, Shorts — mostly similar, minor tone differences)
- Target length (default 15-30 seconds)

## Workflow
1. Write the hook (first 1-2 seconds) — must create a reason to keep watching, spoken or on-screen text.
2. Write the body as a fast sequence of beats, not one long explanation — assume attention drops every few seconds, so re-hook periodically (visual change, new info, question).
3. End with a specific, low-friction CTA (follow for part 2, comment a word, save this).
4. Suggest pacing: where cuts/text overlays should land to sustain retention.

## Output template
```markdown
# Reel concept: <topic>
**Target length:** <seconds>

[HOOK — 0-2s]
<line + visual note>

[BODY — beats]
1. <beat + visual/text overlay note>
2. <beat>
3. <beat>

[CTA]
<line>
```

## Avoid
- A hook that's really just a title card
- One unbroken monologue with no re-hook moments
- Vague CTAs ("let me know what you think")
